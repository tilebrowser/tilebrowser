# TileBrowser

Multi-tile browser for Windows.

- **Website:** [tilebrowser.app](https://tilebrowser.app)
- **Download:** [Latest release](https://github.com/le2280/tilebrowser-releases/releases/latest)
- **Issues:** [Bug reports & feature requests](https://github.com/le2280/tilebrowser-releases/issues)
- **Support:** [support@tilebrowser.app](mailto:support@tilebrowser.app)

This repository hosts **release binaries** and the **public issue tracker** only. Application source code is not published here.

## Download

Installers are attached to [Releases](https://github.com/le2280/tilebrowser-releases/releases). Prefer the latest `.msi` / setup `.exe` for normal installs.

## Reporting issues

Use [Issues](https://github.com/le2280/tilebrowser-releases/issues) for bugs and feature requests. Please include your OS version and steps to reproduce when possible.
