# TileBrowser

A Windows desktop browser for viewing multiple sites side by side as resizable **tiles**. Useful when you want several streams, chats, or dashboards visible at once.

- **Website:** [tilebrowser.app](https://tilebrowser.app)
- **Download:** [Latest release](https://github.com/tilebrowser/tilebrowser/releases/latest)
- **Help:** [English](https://tilebrowser.app/en/help.html) · [日本語](https://tilebrowser.app/ja/help.html)
- **Issues:** [Bug reports & feature requests](https://github.com/tilebrowser/tilebrowser/issues)
- **Support:** [support@tilebrowser.app](mailto:support@tilebrowser.app)

This repository hosts **release binaries** and the **public issue tracker** only. Application source code is not published here.

## Download

1. Get the latest installer (`.msi` / setup `.exe`) from [Releases](https://github.com/tilebrowser/tilebrowser/releases/latest).
2. Install and launch (Windows; uses WebView2).

## Quick start

1. **Add a tile** (`Ctrl + T`) and enter a URL in the address bar (`Ctrl + L`).
2. Drag a tile’s title bar to rearrange; drag edges to resize.
3. Use **Equal layout** to even out open tiles.
4. Open a **page** (single-view) from the left rail; switch between pages and tiles with `Ctrl + Space`.
5. Right-click a link to open it in a new page, tile, or secret tile. `Shift` / `Ctrl`+click also opens links in another tile.

In-app help (with a UI walkthrough) and the full shortcut list are in the app Help menu or on the [help page](https://tilebrowser.app/en/help.html).

### Useful shortcuts

| Shortcut | Action |
| --- | --- |
| `Ctrl + T` | Add tile |
| `Ctrl + L` | Address bar |
| `Ctrl + Space` | Cycle pages and tiles |
| `Ctrl + W` | Close tile / page |
| `Alt + M` | Toggle mute |
| `Esc` | Minimize + mute |

## 日本語

Windows 向けのデスクトップブラウザです。複数のサイトを**タイル**として並べて見比べながらブラウズできます。配信・チャット・ダッシュボードなど、同時に複数画面を見たい用途向けです。

### ダウンロード

1. [Releases](https://github.com/tilebrowser/tilebrowser/releases/latest) から最新のインストーラ（`.msi` / setup `.exe`）を入手します。
2. インストール後に起動します（Windows、WebView2 利用）。

### ざっくり使い方

1. **タイルを追加**（`Ctrl + T`）して、アドレスバーに URL を入力します（`Ctrl + L`）。
2. タイトル帯をドラッグして位置を入れ替え、端をドラッグしてサイズを調整します。
3. **均等に並べる**で、開いているタイルの大きさをそろえられます。
4. 左のタブから**ページ**（1画面ビュー）を開き、タイル表示と行き来できます（`Ctrl + Space`）。
5. リンクは右クリックで「新しいページ／タイル／シークレットタイルで開く」を選べます。`Shift` / `Ctrl`＋クリックでも別タイルに開けます。
